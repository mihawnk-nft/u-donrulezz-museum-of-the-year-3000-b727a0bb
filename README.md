An entry for the [make.fun](https://make.fun/c/u-donrulezz-museum-of-the-year-3000-b727a0bb)
bounty "Museum of the Year 3000" — write one line, the museum label a
museum in the year 3000 puts beside an ordinary object from today.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> Group chat, c. 2025. A nightly ritual in which 43 humans gathered to exchange frog pictures and never once agree on dinner.

123 characters, one line — a deadpan museum label that misreads a group
chat as a nightly ritual: dozens of humans gathering to trade frog
pictures and never once deciding where to eat. The freshest of the
suggested objects (not another fork or parking meter), with the laugh
in the line itself.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
